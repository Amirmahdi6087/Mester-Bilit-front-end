# Mister Bilit 🎫

Hello everyone! 👋

This is my frontend practice project, inspired by the Mister Bilit website.

I created this project using HTML and CSS to practice frontend development and improve my web design skills.

The main focus of this project is the visual design and layout of the website.

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📌 About The Project

This is a frontend-only website project.

It focuses on recreating the visual design and layout of the Mister Bilit website.

There is no backend or real website functionality included in this project.

## 🎯 Project Goals

* Practice HTML and CSS
* Improve frontend development skills
* Learn more about website layouts and styling
* Recreate a real-world website design
